# Archived Streamlit prototype

These files are retained for historical reference only. They are separate from the maintained
Mindsy application, which is the Next.js frontend and FastAPI backend in `frontend/` and
`backend/`.

Do not use this prototype for deployment or real reflections. Its legacy Azure code has different
configuration and does not have the current API's explicit external-processing consent and
fallback safeguards. Its dependencies are independent and are not installed by the maintained
application. No support or security fixes are planned for this archive.
